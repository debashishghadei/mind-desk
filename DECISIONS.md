# Decisions

Numbered so both AIs (Claude and ChatGPT) and the owner can refer to them. Newest last.

- **D1 (21 Oct 2026) Single HTML file, no install.** Opens from the PC in Edge/Chrome. No Python, no server, no Windows installer. `Open Mind Desk.bat` opens it as an Edge app window.
- **D2 Ollama is the main AI; notes stay on the PC.** The notes are very private (personal life, job, salary). Copy & paste with ChatGPT/Claude and an OpenAI-style API (AnythingLLM, LM Studio) are options in Settings.
- **D3 `OLLAMA_ORIGINS=*` is required.** Tested with real Ollama 0.40.7: a page opened from a file sends `Origin: null`; default Ollama answers 403. `OLLAMA_ORIGINS=null` makes Ollama crash at start ("bad origin"). Only `*` works. The README and the app explain the one-time setting and its trade-off.
- **D4 Three AI steps (split → questions → organize), each small.** Small local models do better with one clear job per request. Organize runs one note per request; copy & paste mode bundles all notes per step.
- **D5 Rules first, AI second for splitting.** `makeBlocks` joins obvious pieces (heading + list, `//`/`sol:` follow-ups) and `-----` always separates. The AI can only join blocks, never cut inside one, so it cannot lose or reorder text. The user can split with `---` while editing.
- **D6 Typo fix must keep the person's voice.** Prompt forbids rewriting; My words + ALL-CAPS codes are protected. Checks after each answer: text shorter than 80%, more than 35% of words changed, or a protected word changed → one retry with a stricter instruction, then a warning in Review.
- **D7 Nothing counts until approved.** AI results wait in Review; tasks and categories show only approved items. Originals are always kept.
- **D8 Questions teach the AI.** Word answers → My words (meaning used in prompts, word protected). Intent answers → My rules. Both editable.
- **D9 One main category + tags** (AI tags removed in 1.0.4, see D33). A note can also show in other categories; to-do subcategories have an "area" so job/business/client tasks also show in their area.
- **D10 Storage:** IndexedDB in the browser (localStorage fallback), optional folder copy via the File System Access API, JSON backup/restore, Markdown export.
- **D11 Defaults from the owner's plan:** categories To-do (Chores, Shopping & buying, Job tasks, Business tasks, Client tasks), Mind & life lessons, Job: Madhu Infotech, Clients & side work, My business (Websites & brand, Content ideas, Tool ideas), Personal goals, Unsorted. Default word: Madhutech = Madhu Infotech (job, not own website). Default model `qwen3:8b` (RTX 4060 8 GB); changed to `qwen3.5:9b` in 1.0.3 (D30).
- **D12 Privacy of the repo:** no real notes in the repository; tests use invented notes in a similar style.
- **D13 (21 Oct 2026, review of 1.0.0) One working window.** Web Locks (`mind-desk-window`) give one window the right to work; others show "Use Mind Desk here" (steal). Saving also checks a revision number in the same storage transaction and stops if newer data exists (backstop without locks).
- **D14 Never write after a failed load.** A failed IndexedDB open or read shows an error screen; `save()` is disabled. localStorage is used only when IndexedDB does not exist at all.
- **D15 Backups are fully checked before restore** (`backupProblem`); restore keeps this PC's AI connection settings; backups never include the API key.
- **D16 Splitting is line based.** Each line may become a block; list lines, `//`/`sol:` follow-ups and lines under a heading stay attached; blocks written without an empty line are marked "(same paragraph)" for the AI. Dividers force a new item even if the AI joins.
- **D17 Meaning checks.** Character edit distance (> 30% and > 4 characters) replaces the word ratio; numbers/dates, negation words, URLs and e-mails must survive. Task "done" needs a sign in the note; unsupported or negated tasks are flagged.
- **D18 Context size grows with the note** (estimate chars/3.2 + answer + 768, rounded up, max 32,768). Larger items must be split by the user.
- **D19 Busy rule.** While the AI runs, actions that delete or replace data are blocked; late answers for deleted items are dropped.
- **D20 OLLAMA_ORIGINS=* stays for now** (review point R16 is a fair trade-off point). Alternative for later, owner's choice: a launcher that serves Mind Desk from `http://127.0.0.1:<port>`, which Ollama allows by default, so `*` is no longer needed (data would move to that address once).
- **D21 (21 Oct 2026, review of 1.0.1) One write at a time**; a change during a write is written right after. Folder bookkeeping saves never schedule another folder copy.
- **D22 Recovery copy.** A window that loses control with unsaved work stores it under a separate key (`recovery`), never over the main data; the window in charge shows it (on start and when the window gets focus) to download, use or delete.
- **D23 Folder writes are abandoned when control is lost** (checked before writing and before `close()`, which is when a file is replaced).
- **D24 Ids are simple** (`[A-Za-z0-9_-]{1,64}`, checked on restore) and always escaped in HTML / `CSS.escape` in selectors.
- **D25 Split originals by word alignment** with typo tolerance (up to ~2,000 words per side); beyond that an approximate cut at the same share of words, flagged `splitguess`.
- **D26 Meaning checks v2:** comparison line by line (fast, no false alarm on long notes); numbers in order (words like 2day/b2b are not numbers; 14th, 10k, 1L, 50% are); "not"-words per line with the first letter of the next word; done/support judged per clause (split at line, `;`, `,`, `..`); a task needs ≥ 75% of its words in the note (typos and short forms count).
- **D27 Lock failure is not fatal:** if Web Locks fail, Mind Desk runs with the revision check only and shows "one-window check off".
- **D28 (22 Oct 2026) Fast / Careful per run**, chosen next to Organize all (and per item in "Ask AI again"). Careful = Ollama `think: true` for the steps ticked in Settings (default all). Thinking is stored (`note.splitThinking`, `survey.thinking`, `item.thinking`, max 20,000 chars) and shown folded. Owner's wish: thinking on for quality, hidden by default.
- **D29 Careful requests do not send a JSON schema** (`format`), because a fixed format can stop some models from thinking; the JSON shape is asked for in words and checked as usual (one retry). Careful adds 4,096 tokens of context and doubles the time limit. A model that rejects the thinking switch is remembered for the session and asked normally.
- **D30 Default model `qwen3.5:9b`** (6.6 GB, fits the RTX 4060 8 GB; owner installed it 22 Oct 2026). Alternatives: `qwen3.5:4b` (faster), `gemma4:12b`.
- **D31 1.1.0: Chat + Memory** (built 22 Oct 2026, see D37–D40). Chat page with history; questions answered from notes Mind Desk finds itself; actions only as Apply/Cancel cards; Memory list (includes My words & rules) sent with every request and kept by Mind Desk, so it works with any model or provider.
- **D32 (22 Oct 2026, after the first real run) Streaming + live panel + thinking limit.** Ollama requests use `stream: true`; the app reads NDJSON, shows seconds and state, and in Careful mode the last 600 characters of thinking. Thinking beyond `thinkLimitSec` (default 120) is cancelled and the request repeated without thinking (`thinkcut` flag). Reason: Careful "looked stuck" for the owner.
- **D33 One place rule** (owner): one category per note, no AI tags (prompt no longer asks; app ignores), old AI tags cleared once via `schema` 2; tasks only in To-do, category pages link there; Markdown does not repeat tasks.
- **D34 Writing style setting** `editStyle`: `typos` (default, keeps voice) or `clean` (rewording allowed; `bigchange` not checked and `shortened` relaxed; numbers, negation, protected words still checked). Prompt placeholder `{{editRule}}`. Default chosen by Claude because the owner did not answer; owner said a cleaner rewrite "is fine".
- **D35 Fix my typing** uses its own prompt (`fix`) with the same edit rule and meaning checks; the result is only applied after the owner chooses "Use the fixed text".
- **D36 Report for Claude** (`buildReport`): plain text, preview first, names hidden by an editable list (detected capitalised words mid-sentence), never the API key; runLog (last 300 requests: step, note, mode, ms, ok, cut) is stored in the state but left out of backups.
- **D37 (22 Oct 2026, 1.1.0) Chat context is chosen by Mind Desk, not the AI** (`buildChatContext`): overview (last 30 notes, item counts per category), up to 2 named notes with their items, up to 8 best-matching items (title ×3, category ×2, text ×1, 4-letter prefix matches), tasks when the message is about to-dos (filtered by named category/area) or that match words; ~9,000 characters budget. Reason: small local model, privacy (unrelated notes are not sent), speed.
- **D38 Chat never acts by itself.** The AI returns `{reply, actions, remember}`; `checkChatActions` keeps only known types with ids that exist (max 8); each action is a card with Apply/Cancel, status saved in the chat. `organize_again` stores `note.instruction` (used in split and organize prompts for that note until removed).
- **D39 Memory replaces "My rules"** (`state.memory`, schema 3 migrates rules once). Sources: chat ("remember"), Review category change ("Teach Mind Desk"), question answers, manual. Sent as "The person's rules"/"Memory" in organize, fix and chat prompts. Warning above 3,000 characters.
- **D40 Chat storage:** `state.chats[{id,title,createdAt,updatedAt,messages[{id,role,text,at,thinking?,actions?,remember?,dropped?,error?}]}]`, max 500 messages per chat, included in backups and validated (`backupProblem`). Answers render text escaped; only `[[item:ID]]`, `[[note:ID]]` and `**bold**` become markup.
- **D41 (22 Oct 2026, 1.2.0) Second build: the claude.ai artifact.** Same `src/`; `bin/build.js` writes `mind-desk.html` (TARGET "pc") and `mind-desk-artifact.html` (TARGET "artifact": a page fragment with `<title>` first, plus `src/platform-artifact.js` and `src/artifact.css`). In app.js `ART` switches the few differences. Reason: the owner wants to use his Claude plan without API cost and on the phone; one source keeps both versions in step. The cloud version (Hostinger) will be a separate repo.
- **D42 Claude provider (`provider: 'claude'`, artifact only)** through the `sample` capability: Fast → `modelTier: 'quick'`, Careful → `'default'`; `cache: false` (every press asks again); no page-side timeout (the platform ends long calls). Steps reuse the batched copy & paste paths (`batched()`, `askBatch`): split and questions in parts of ≤30,000 characters, organize ≤15 notes / ≤12,000 characters per request. A part whose answer cannot be read twice is redone note by note (bounded, never a loop); serious flags get one stricter single request (`strictAgain`, shared with the PC path). Errors: not_granted, sampling_disabled, rate_limited, session_expired, capability errors, missing sample → stop the run with a plain message (`e.conn`), never retried; refused / empty / upstream / too large → that item fails with `aierror` and keeps its text. Truncated answers are not retried.
- **D43 Artifact storage** in the viewer’s private subtree `data/users/<user.id()>` of the artifact database: records `meta` (everything except notes/items/tasks/chats, plus the key order), `note:<id>` (note + its items + their tasks), `loose` (tasks and items without a note), `chat:<id>`, `recovery`. Each record is JSON text cut into documents of ≤60,000 characters (`k.<key>`, `k.<key>+1` …; part 0 written last and carries `n`, `rev`, and for meta `session`), so a document stays under 256 KiB even for Odia/Hindi text. Only changed records are written; deleted notes/chats and leftovers are removed after meta. A save first reads meta’s `rev` and refuses to overwrite a newer one (`blockWindow('changed')`); a live `onSnapshot` on meta does the same when another device/tab (other `session`) saves. Missing parts on load → stop with “Nothing was changed”. No database (signed out, preview) → IndexedDB in the browser, shown in the save line.
- **D44 In-page questions:** `ask(message, {input, okText, danger})` replaces the 15 `confirm`/`prompt` calls. On the PC it still uses the browser dialogs (so behaviour and the PC tests stay the same); the artifact shows its own dialog (Escape/Cancel = no). `leaveEditor()` returns `true` at once when nothing is unsaved, otherwise a promise.
- **D45 Artifact files** go through the `downloads` capability (the viewer confirms each file); restore uses the normal file input. The theme follows claude.ai (the app never sets `data-theme` in the artifact). Hidden there: Ollama/OpenAI/copy & paste settings, folder saving, Theme.
- **D46 Phone layout (both builds):** under 820 px the ☰ button opens the menu over the page (tap outside or choose closes it); the top bar wraps. Tested at 400 px for sideways scrolling.
- **D47 (22 Oct 2026, 1.2.1) Model choice in the artifact** (owner asked to choose the model, e.g. the one he chats with): settings `claudeFast` / `claudeCareful` = 'auto' or a model id from `CLAUDE_MODELS` (claude-haiku-5-5, claude-sonnet-5-5, claude-opus-5-5, claude-fable-5-1), `claudeEffort` = auto/low/medium/high for Careful. A named model is sent as `model` with the same `modelTier` as before (quick for Fast, default for Careful), so claude.ai falls back to the tier when the plan cannot run it; Fast with a named model sends `effort: 'low'`. `modelApplied`/`modelTierApplied` are stored as `item.model`, chat `message.model` and in the run log ("tier:quick" when the tier answered); one toast per session when the chosen model did not answer. Unknown saved ids fall back to 'auto' on load. Defaults stay 'auto' (cheapest on the plan's limits).
