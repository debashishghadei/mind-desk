Mind Deskfirst-time setup

1. Create your login

The setup code is in the file SETUP-CODE.txt in Mind Desk's data folder on your server (the server also printed it when it started).

2. Two-step code

  1. On your phone, open an authenticator app (Google Authenticator, Microsoft Authenticator…).
  2. Add an account → Enter a setup key. Name: Mind Desk. Key: (time based).
  3. Type the 6-digit code the app shows.

3. Keep your recovery codes

If you lose your phone, each of these codes lets you log in once instead of the 6-digit code. Write them down or save them in your password manager. They are shown only now.
